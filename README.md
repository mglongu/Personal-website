# Maria Grazia Longu — CV

> I love making my life easier. I get paid to do the same for others.

Personal CV website styled like a terminal: black page, glowing monospace text,
and a soft light that follows the mouse. The sections (biography, curriculum,
projects, achievements, contact) open and close on click; the curriculum is a
timeline.

Plain HTML, CSS and JavaScript — no build step. Served with GitHub Pages.

- `index.html` — content, SEO meta tags and schema.org data
- `styles.css` — terminal look (VT323 + JetBrains Mono), glow, timeline
- `script.js` — opening/closing sections, typed prompt, mouse light

Link straight to an open section with `#biography`, `#curriculum`, `#projects`,
`#achievements` or `#contact`.
